# 🌱 KnowYourRoot — আপনার শিকড়কে জানুন

> **Interactive Bangladesh Heritage, Gastronomy & Culture Odyssey across all 64 Districts.**

A modern React web application built with **React**, **Vite**, and **HTML5 Canvas** to celebrate the indigenous gastronomy, centuries-old traditions, and Geographical Indication (GI) heritage of Bangladesh. Inspired by authentic regional culinary storytelling (such as Bogura's yogurt, Pabna's ghee, Natore's kachagolla, and Cumilla's roshomalai).

---

## 🌟 Highlights & Features

- **Interactive Vector Map of Bangladesh**:
  - High-precision SVG polygon map of all **64 districts** across **8 divisions** with centroid coordinates.
  - Accelerated rendering with HTML5 Canvas and `Path2D` vector hit-testing.
  - Hover tooltips showing division, district name (Bilingual বাংলা / English), primary delicacy, and tasting status.
- **Custom Taste Passport Generator**:
  - Personalize with your name or traveler alias and custom avatar photo.
  - Switch between 4 curated color themes: **Emerald Heritage (পান্না সবুজ)**, **Clay Terracotta (পোড়ামাটি)**, **Midnight Royal (নীল রাত)**, and **Sunset Glow (গোধূলি আভা)**.
  - High-resolution **1200 × 1600 px** canvas export ready for Instagram, Facebook, and social sharing.
  - Interactive celebration confetti upon export.
- **District Explorer & Culture Hub**:
  - Comprehensive index for all 64 districts covering origin history, authentic shops/spots, secondary specialties, and cultural landmarks.
  - Multi-tier filtering by division and category (*Sweets & Desserts, Savory & Meat, Pitha & Bakery, Fruits & Agri, Fish & Seafood*).
  - Real-time search by district name, delicacy, or location.
- **Food & Heritage Trivia Quiz**:
  - 5-question trivia game testing knowledge of regional Bengali delicacies.
  - Instant educational feedback with historical background notes.
  - Score rating and Connoisseur badges.
- **Bilingual Interface**:
  - Seamless instant toggle between **বাংলা (Bengali)** and **English**.

## 🛠️ Tech Stack

- **Frontend**: React 18
- **Bundler & Tooling**: Vite
- **Styling**: Vanilla CSS (Tailored Design System, CSS Variables, Glassmorphism, Micro-animations)
- **Vector Graphics & Canvas**: HTML5 Canvas 2D Context, Path2D, SVG Paths
- **Visual FX**: canvas-confetti

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/NaimurRahman-11/KnowYourRoot.git

# Navigate to project directory
cd KnowYourRoot

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
